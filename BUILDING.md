# Building the macOS application

The authoritative build guide lives at **[`docs/BUILDING.md`](docs/BUILDING.md)**.

It covers preparing the environment, which FFmpeg build to bundle and why a
GPL one is refused, the LGPL configure recipe, the build environment
variables, what the build verifies on the extracted archive, signing and
Gatekeeper, the application icon, and recording the model digests.

This file is a pointer so that a reader who looks for `BUILDING.md` at the
repository root finds their way there, and so the instructions only ever
exist in one place.
